Advanced: interval tuning & intonation style

The Highland pipe scale isn't equal-tempered — each note sits a characteristic number of cents away from a "piano-tuned" pitch. Defaults below use the modern-convention just-intonation intervals (harmonic 7ths for both Gs, just fourth for D). Real chanters and reeds vary — adjust any row to match yours by ear.

Setup & permissions notes

• Microphone access requires HTTPS or localhost — it will not work if this page is opened from a plain http:// address or a bare file:// path in some browsers.

• The permission prompt only appears after you tap “Start tuning” — browsers block sites from requesting the microphone automatically.

• On iPhone/iPad, Safari shows a one-time system dialog. If you deny it, re-enable it under Settings → Safari → Microphone (or Settings → [this site] if installed as an app).

• You can install this as a home-screen app (share icon → “Add to Home Screen”). Mic access generally works in installed iOS web apps, but has occasionally had quirks across iOS versions — test it after installing, and keep the browser tab version as a fallback.

Frequencies are calculated as Low A × 2^(semitones⁄12) × 2^(cents⁄1200). Pitch is detected client-side via autocorrelation on the raw microphone signal — nothing is uploaded anywhere. Your Low A, interval settings, and tuning log are stored only in this browser.
